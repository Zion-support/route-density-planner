# Route Density Planner

> More jobs per day, fewer miles per job

Field-service routing AI that clusters jobs geographically, respects SLAs and skills, and slashes windshield time.

**Live:** https://ziontechgroup.com/route-density-planner/  
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- Density-based job clustering per technician
- SLA, skill and parts-aware route assignment
- Dynamic re-routing on cancellations and emergencies
- Fuel and overtime savings estimator
